Privacy Policy

Video Pipeline Tool · last updated September 22, 2026

This tool is a private, internal utility used by a small team to manage stream recordings and clips. It is not a public product, and it is not distributed or offered to anyone outside that team.

What it accesses

The tool uses Google's Drive API, authorized directly by whoever runs the one-time sign-in, to:

  • Upload video files (stream recordings and clips) into a specific Google Drive folder
  • Read, rename, and organize files within that same folder
  • Remove files from that folder when they're deliberately deleted from the tool

It does not access any other files, folders, or data in the connected Google account beyond what the tool itself creates or is pointed at.

What it doesn't do

  • It does not sell, share, or transmit this data to any third party
  • It does not use the data for advertising, analytics, or profiling of any kind
  • It does not run on any server other than the machine it's installed on (an internal streaming rig)

Where data lives

Video files stay in Google Drive, in the account that authorized access. Metadata about clips (titles, notes, status) is stored in a private Firebase database used only by this tool, accessible only to the small team operating it.

Revoking access

Access can be revoked at any time from Google Account → Security → Third-party access.

Questions about this tool or this policy: contact the account that authorized access.
